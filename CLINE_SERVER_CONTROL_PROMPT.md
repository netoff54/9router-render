## 💡 Pro Tips

1. **Keep server context alive** - Cline akan remember server info dalam conversation
2. **Be specific** - Tell Cline exactly what to check or fix
3. **Use natural language** - No need for technical commands, Cline understand
4. **Ask for summaries** - "Summarize the current state of the server"
5. **Request automation** - "Automate health checks" (Cline dapat remind untuk check)
